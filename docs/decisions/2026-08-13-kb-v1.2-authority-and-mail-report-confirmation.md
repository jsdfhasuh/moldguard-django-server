# MoldGuard 知识库 V1.2 权威性与邮件报工链接确认

- **状态**：`OWNER_CONFIRMED`
- **日期**：2026-08-13
- **知识库快照**：`MOLDGUARD-KB-1.2`

## 1. 权威结论

用户确认：发生业务规则、字段或流程冲突时，以最新上传知识库为最终解释。

因此，知识库 V1.2 优先于早期 V3.x/V4.1 计划及此前冲突决策记录。

## 2. 被覆盖的旧口径

- 钣金不再统一按开发吨位 30K/50K；按知识库的成型 150K、冲孔落料/连续/边板 400K；
- 注塑 2 个月条件不再是“只提醒”，而是自动建立时间周期保养工单；
- 正常报工不再进入额外主管验收，服务器校验后直接完成；
- 异常报工进入 `ABNORMAL_REPORTED`，继续处理或关联修模；
- 字段统一采用 `effective_mold_cycles`、`baseline_effective_mold_cycles`、`baseline_maintenance_at` 等知识库口径。

## 3. 新增邮件报工链接决策

- 派工邮件携带本次适用的一份点检知识包；
- Django返回 `report_url` 和按钮文字“提交报工情况”；
- 被派工人员点击链接，在Django页面提交正常或异常报工；
- 智能体平台不得自行生成或改写报工链接；
- 邮件、报工页面和数据库使用同一知识快照版本；
- 正常报工自动完成和复位；异常报工不完成、不复位。
