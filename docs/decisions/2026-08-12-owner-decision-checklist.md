## 1. 使用方法

1. `A 类决策`必须在 Django Phase 0 结束前确认；未确认时不得把相关知识规则写成自动业务规则。
2. `B 类决策`必须通过比赛平台 Gate -1 最小链路验证。
3. `C 类决策`决定申报材料和答辩口径，必须在提交参赛材料前确认。
4. `D 类决策`可以推迟到 P1，不阻塞参赛主链路。
5. 每项决策请填写：`选择、负责人、确认日期、备注`。
6. 采用推荐项时，也应留下明确确认记录，不能把“模型建议”当作业务批准。

推荐回复格式：

```text
D01=A
D02=A
D03=C
...
负责人：蔡家浩
备注：按推荐项冻结比赛版，企业正式规则后续再确认
```
