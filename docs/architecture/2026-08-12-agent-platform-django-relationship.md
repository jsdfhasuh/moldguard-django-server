# 智能体平台与 Django 最小测试服务器关系说明

- **版本**：V2.1
- **日期**：2026-08-13
- **适用计划**：`docs/plans/2026-08-12-moldguard-django-implementation-plan.md` V4.1
- **服务器定位**：无角色、无鉴权、无历史导入的比赛模拟服务器

---

## 1. 一句话说明

> **智能体平台负责对话、知识和邮件；Django负责模拟数据、规则计算和工单状态。**

```text
智能体平台
= 对话 + 工作流 + 知识库/RAG + LLM + 邮件

Django
= 模具 + 提醒 + 人员 + 工单 + 状态 + 履历 + 统计
```

---

## 2. 总体架构

```text
比赛智能体平台
├─ 自然语言交互
├─ 工作流编排
├─ 知识库检索
├─ LLM生成内容
├─ 操作人员选择候选人和验收结果
└─ 邮件发送
          │ HTTP + JSON
          ▼
Django Test Server
├─ 模具与周期基线
├─ 30,000/50,000规则
├─ 模次提醒与2个月提醒
├─ 模拟人员和候选匹配
├─ 工单、派工和状态机
├─ 点检JSON、知识JSON和邮件结果
├─ 保养/修模/换镶件复位
└─ 工时与完成率
          │
          ▼
        SQLite
```

---

## 3. 智能体平台负责

- 理解用户查询；
- 触发 Django 接口；
- 检索保养项目、点检、安全和验收知识；
- 生成预警和任务说明；
- 展示候选人员；
- 由平台操作人员选择派工人；
- 由平台操作人员选择验收、退回或转修模；
- 发送任务邮件；
- 把最后一份知识快照和最后一次邮件结果回写 Django；
- 根据 Django 统计结果生成自然语言分析。

平台不得自行修改模具模次、阈值、工单状态或周期基线。

---

## 4. Django负责

- 模具编号、类型、开发吨位、累计模次、位置和产线；
- 当前周期基线；
- 按吨位选择 30,000 或 50,000 模次阈值；
- 创建模次到期提醒；
- 创建注塑模具每2个月信息提醒；
- 保存模拟人员、技能、负荷和测试邮箱；
- 创建工单并防止重复工单；
- 返回候选人员并在派工时重新校验；
- 保存工单状态和时间线；
- 保存单份点检 JSON；
- 保存单份知识快照 JSON；
- 保存最后一次邮件结果；
- 验收完成、修模完成、换镶件完成时复位周期；
- 保存系统产生的履历；
- 返回工时和完成率。

---

## 5. Django不负责

```text
用户登录
主管或其他角色
API鉴权
历史记录导入
保养计划和送模
健康评分
复杂规则审批
知识库全文
SMTP和邮件发送
完整修模流程
生产级安全和容灾
```

## 6. 核心交互流程

### 6.1 巡检

```text
平台 POST /alerts/scan
→ Django按开发吨位计算阈值
→ Django返回模次提醒和2个月提醒
→ 平台生成说明
```

模次提醒可以创建工单；2个月提醒只通知。

### 6.2 建单和派工

```text
平台选择模次到期提醒
→ POST /work-orders
→ Django创建待派工工单
→ GET /candidates
→ 平台操作人员选择人员
→ POST /assign
→ Django保存派工
```

### 6.3 知识和邮件

```text
平台 GET /knowledge-context
→ 检索知识库
→ POST /knowledge 保存最后一份JSON
→ 平台发送邮件
→ POST /email-result 保存最后一次结果
```

### 6.4 执行和验收

```text
assign
→ start
→ pause / resume
→ inspection
→ report-complete
→ accept / reject / transfer-to-repair
```

Django只校验状态和数据完整性，不校验操作人角色。

### 6.5 周期复位

```text
accept                → 保养完成复位
repair-completed      → 修模完成复位
insert-replaced       → 换镶件完成复位
```

不提供历史导入复位。

## 7. 数据权威关系

| 内容 | 权威来源 |
|---|---|
| 模具、模次、开发吨位、周期基线 | Django |
| 30,000/50,000触发结果 | Django |
| 工单、派工和状态 | Django |
| 模拟人员和邮箱 | Django |
| 点检执行结果 | Django中的工单JSON |
| 保养和验收知识正文 | 智能体平台知识库 |
| 最后一次知识快照 | Django中的工单JSON |
| 邮件正文 | 智能体平台 |
| 最后一次邮件状态 | Django工单字段 |
| 自然语言分析 | 智能体平台 |

---

## 8. 最终关系总结

```text
智能体平台让系统会理解、会检索、会表达、会发邮件。
Django让演示数据可查询、工单状态可变化、周期可复位、统计可计算。
```

两端只保留比赛主链路，不建设企业生产系统。
