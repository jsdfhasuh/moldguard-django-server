# MoldGuard 模具保养知识库最终冻结版 V1.2

> 知识快照：`MOLDGUARD-KB-1.2`  
> 发布日期：2026-08-13  
> 状态：`FINAL_FROZEN`  
> 适用范围：AI智能体比赛知识库、MoldGuard Django测试服务器、派工知识包与报工校验。  
> 流程口径：不设置主管、管理员审批、审核或验收角色；派工邮件携带本次适用点检知识和Django生成的报工链接，被派工人员点击链接直接提交正常或异常报工。

## 0. 使用边界

本知识库只分为两部分：

1. **触发保养标准**：判断何时自动建立保养工单、何时停止自动触发，以及何时复位周期；
2. **保养内容、点检、储放、安全、故障工时与邮件链接报工**：说明任务建立后如何执行、检查、记录、异常处理和报工。

### 0.1 权威口径

- 注塑和钣金的自动触发阈值，只采用《模具保养标准.pptx》两页业务简述；
- 技术作业内容采用内部模具保养标准、点检表、储放与安全规范；
- 故障标准工时采用《模具故障标准.xlsx》；
- 本项目不使用模具寿命等级、一级/二级/三级保养周期、A级/B级/C级保养分类或其他历史触发数字；
- “一级位置、二级位置”仅表示钣金模具位置字段，不表示保养等级；
- 本知识库使用“日常保养、生产前后基础保养、周期保养、下机拆模保养、修模换件同步保养、入库前处理”等作业范围，不设置保养等级字段。

### 0.2 规则优先级

1. 已确认的项目业务决策；
2. PPT中的触发保养标准；
3. 内部保养、点检、储放和安全作业内容；
4. 故障与维修工时表。

当详细作业资料出现与PPT不同的历史触发数字时，只保留作业步骤，触发判断仍以第一部分为准。

### 0.3 已确认的十一项业务决策

| 决策项 | 最终口径 |
| --- | --- |
| 1 | 达到触发条件后自动建立工单，状态为 `PENDING_ASSIGNMENT`，由智能体或接口指定被派工人员。 |
| 2 | 注塑每日保养、钣金生产前后保养及12/24/48小时固定作业作为轻量记录，不复位产量周期或时间周期。 |
| 3 | 产量阈值保养、2个月时间保养、下机修模或换镶件后完成的有效保养，正常报工后统一复位产量与时间周期。 |

| 11 | 派工邮件必须包含本次适用点检知识和Django返回的 `report_url`；被派工人员点击链接填写完成情况、点检结果和异常情况，正常报工自动结单，异常报工进入异常闭环。 |

# 第二部分｜保养内容、点检、储放、安全、故障工时与邮件链接报工

## 1. 无主管角色的业务闭环

```text
服务器满足触发条件，或人员手动建单
→ 自动建立工单：PENDING_ASSIGNMENT
→ 智能体或接口指定 assignee_id：ASSIGNED
→ Django返回被派工人员邮箱和report_url
→ 智能体平台检索本次适用点检知识并发送派工邮件
→ 被派工人员点击邮件中的“提交报工情况”链接
→ 在Django报工页面查看点检知识、填写完成情况和点检结果
→ 提交正常报工或异常报工
→ 服务器自动校验
   ├─ 正常报工且适用必检项完整：按工单类型完成结单，并按复位矩阵处理周期
   └─ 存在不合格、未处理异常或必填缺失：进入异常流程，不结单、不复位周期
```

本项目不设置主管、管理员审批、审核、验收、批准、驳回或“两次关闭”节点。派工人员只负责通过智能体或接口指定被派工人员，不承担审批角色。

| --- | --- | --- | --- | --- | --- |
| 模具正在生产 | 注塑模具 | `LIGHTWEIGHT_DAILY` | 生产中每日保养与检查 | 否 | 否 |
| 生产前 | 钣金模具 | `LIGHTWEIGHT_PRE_PRODUCTION` | 生产前基础保养 | 否 | 否 |
| 生产完成后 | 钣金模具 | `LIGHTWEIGHT_POST_PRODUCTION` | 生产后基础保养 | 否 | 否 |
| 12/24/48小时固定频次 | 钣金模具 | `LIGHTWEIGHT_FIXED_FREQUENCY` | 清洁、润滑、紧固及随时检查 | 否 | 否 |
| 模具入库或储放检查 | 注塑/钣金 | `STORAGE_INSPECTION` | 清洁、吹水、防锈、完整性和储放检查 | 否 | 否 |
| 达到注塑30000/50000模次或钣金150000/400000模次 | 注塑/钣金 | `CYCLE_COUNT_MAINTENANCE` | 对应周期保养或专项保养 | 是 | 是 |

## 3. 注塑模具保养

### 3.1 生产中日常保养

生产中的模具要求**每天进行一次保养与检查**。基本内容包括：

- 清洁。
- 润滑。
- 螺丝紧固。
- 易损件检修。
- 玻纤材料对应模具的镶针、风叶轴芯或类似结构，涉及关键装配尺寸时进行检修或备件更换。
- 磨砂重点外观面检查纹路是否异常。
- 薄、细部位检查是否缺损、开裂、变形。

该要求属于生产现场固定作业，不增加新的服务器产量阈值。

### 3.2 下机拆模保养

| 保养模块 | 要求 |
| --- | --- |
| 清洁 | 清除模具外表面、分模面、型腔表面、导柱表面、顶针底面上的油污杂物、粉尘及锈斑，确保干净无异物。 |
| 紧固 | 使用扳手对滑块压板、耐磨块、二次分模导柱导套等位置螺钉进行紧固；锁模块完整并可正常使用。 |
| 润滑 | 对导柱、复位杆、滑块、耐磨块等运动部位进行润滑；检查模具活动部分动作时是否存在异常响声，各滑动部分运动是否灵活，动作时有无振动及卡死。 |
| 冷却系统 | 检查模具接水方式是否正常、水道是否流畅、是否漏水，以及是否存在因冷却不良造成的模具烧伤。 |
| 易损件检查 | 针对多顶针、多动作、易磨损模具，检查顶针是否烧伤、滑动件运动是否正常、易损镶件是否完好。 |
| 热流道 | 检查热流道系统是否正常，浇口出胶是否正常、是否多胶。 |
| 毛刺 | 检查模具是否突增毛刺，并分析产生原因，包括注塑参数合理性和模具是否磨损。 |
| 导向部分 | 检查导柱、导套、斜导柱、复位杆、二次分模限位杆、复位导柱导套、动定模固定锥面等磨损状况。 |
| 顶出部分 | 检查顶针、斜顶及斜顶固定装置是否磨损，顶针板、固定板是否变形，顶针防尘板是否完整。 |
| 排气部分 | 检查经修复分型面的排气系统是否排气流畅。 |

### 3.3 使用、调拨与完整性

- 所有模具调动到其他基地生产前，应完成下机拆模保养。
- 闲置模具有生产计划时，应先从仓库调回使用单位进行拆模保养。
- 完成拆模保养并上传有效保养记录后，恢复至可正常下单生产的状态。
- 完成保养入库或调动到其他基地的模具，应检查完整性；发现配件缺失时应安排制作或更换。
- 修模、改模或更换备件时，应同步执行适用保养并完成点检；由被派工人员邮件链接报工。

## 4. 钣金模具生产前后基础保养

### 4.1 作业时机

- 所有适用的LC钣金模具，生产前和生产完成后均执行基础保养；
- 生产中的换料、转班和中间休息时间可安排保养，每次15—30分钟；
- 基础内容包括清洁、润滑、紧固防松和隐患检查。

### 4.2 安全隔离

1. 模具安装在压力机上时，基础保养为不拆卸保养；
2. 保养时按现场正式安全操作规程使设备进入停止、断电并防止误启动的状态；
3. 上下模保持安全分离；
4. 完成现场规定的警示、隔离或挂牌措施；
5. 发现异常或无法处置时立即停止作业并提交异常报工；异常未排除、设备安全条件未恢复前不得重新开机生产。

### 4.3 基础保养步骤

1. 跟踪、检查模具安装调试过程是否符合操作指导书。
2. 使用干净布头、软细棒类器械等清理模具上的废料、污垢和产品冲压、成形时产生的沉积物。
3. 使用内六角扳手等专用工具拧紧模具中可紧固的紧固件，包括上、下模限位柱、导柱等。
4. 检查模具刃口、成形部位的完好性；轻微损伤可使用金刚锉、油石或细砂纸修磨刃口或成形面。
5. 使用高压气体吹净模具型腔内的丝状、小颗粒等影响模具刃口、滑块滑动和产品外观的杂物。
6. 使用干净布头或纱头擦拭模具型腔、导向件和外观，保持清洁、外观标识清晰。
7. 检查导向件和模具可滑动部分的松紧情况，并适当加油润滑。
8. 发现镶件、冲针凸模、导正销等异常且无法现场处理时，立即停机并提交异常报工。
9. 按本知识库点检清单逐项记录并由被派工人员邮件链接报工。

### 4.4 生产中固定频次

| 模块 | 频次与要求 |
| --- | --- |
| 清洁 | 每12小时至少对模具型腔可视面、落料孔进行清理、检查一次。 |
| 润滑 | 每24小时对导柱、导套进行润滑。 |
| 紧固 | 每48小时对压板螺钉及相关快换结构螺钉进行紧固，并紧固到位。 |
| 检查 | 根据生产实际情况随时关注抖动盘送料是否异常、废料落料是否顺畅、传送是否顺畅。 |

这些频次属于生产中固定保养要求，不作为服务器的150000/400000模次自动触发阈值。

## 5. 钣金模具产量触发专项保养

> 本节只保留不同模具类型的检查和处理步骤。所有触发阈值统一采用第一部分，不使用其他历史周期。

### 5.1 成型类专项保养

适用触发阈值：**150000模次**。

1. 检查导套是否磨损，导柱是否松动、弯曲、变形，钢珠衬套是否磨损、变形或丢失；更换磨损变形的导套、钢珠衬套和弯曲变形导柱，补齐丢失的钢珠衬套。
2. 检查上下模压料板是否弯曲、变形或有凹坑；弯曲变形时修整并用磨床磨平，存在高度差且不能磨平时重新更换；凹坑用磨床磨平或镶拼补平。
3. 检查卸料板螺钉是否断裂、弯曲；断螺钉需钻通螺钉孔并重新攻螺纹孔，更换弯曲损坏的卸料螺钉；断螺钉有三个或以上时更换全部卸料螺钉。
4. 检查定位销、定位块是否可靠、无松动，是否磨损或缺少；重新加固松动的定位，更换、补齐磨损或缺少的定位。
5. 检查上下模弹簧是否断裂、变形、压缩量失效，氮气弹簧是否漏气失效；更换异常弹簧或氮气弹簧；断裂弹簧有三个或以上时更换全部弹簧。
6. 检查成型凸模、成型凹模和拼块是否走位、松动；有走位或松动时更换全部凸凹模销钉并重新装配。
7. 检查成型凸模、成型凹模是否损坏或有裂纹，成形表面是否磨损、表面光洁度是否达标；可镶补时镶补，不能镶补时更换；表面磨损或光洁度不足时进行抛光处理。
8. 检查成型滑块、滑槽是否磨损破裂，滑动是否卡死或不顺畅；更换破损滑块组件，重新修配并保证滑块来回活动顺畅。
9. 完成检查和更换后重新固定所有螺钉，清理凸凹模及上下模板锌皮废料，对导柱、导套、内导柱、滑块加润滑油，保持外观整洁、无油污、无生锈。

### 5.2 冲孔落料类专项保养

适用触发阈值：**400000模次**。

1. 检查导套是否磨损，导柱是否松动、弯曲、变形，钢珠衬套是否磨损、变形或丢失；更换或补齐异常部件。
2. 检查上下模压料板是否弯曲、变形或有凹坑；按情况磨平、镶拼或更换。
3. 检查卸料板螺钉是否断裂、弯曲；断螺钉需钻通并重新攻丝；断裂三个或以上时更换全部卸料螺钉。
4. 检查定位销、定位块是否可靠、无松动，是否磨损或缺少；加固、更换或补齐。
5. 检查上下模弹簧是否断裂、变形、压缩量失效，橡皮是否开裂损坏、压缩量失效；更换异常弹簧或橡皮；同类损坏三个或以上时更换全部相应件。
6. 检查冲切凸模、冲切凹模和拼块是否走位、松动；有走位或松动时更换全部销钉，重新装配并校正间隙。
7. 检查冲切凸模、冲切凹模是否损坏或有裂纹，冲切刃口是否磨损钝化；可镶补时镶补，不能镶补时更换；刃口钝化时用磨床磨至锋利并重新配间隙。
8. 检查圆冲头、异型小冲头是否弯曲、磨损、不锋利，翻边冲头、顶破冲头是否弯曲或破损；更换异常冲头；异常三个或以上时更换全部相应冲头并重新配间隙。
9. 检查凹模漏料孔、翻边孔顶芯漏料是否顺畅无堵塞，顶芯顶力是否合适，各退料切刀是否锋利无缺；堵塞时加大漏废料孔并相应减少刃口高度（孔直径1.2至4，刃口高度2.5—5mm）；顶芯堵塞时更换并调整顶料力；更换磨损退料切刀并补齐缺少切刀。
10. 检查侧冲孔滑块、滑槽是否磨损破裂，滑动是否卡死或不顺畅；更换破损滑块组件并重新修配。
11. 完成后固定所有螺钉，拧紧快换顶丝（必须双顶丝互锁），清理凸凹模和模板锌皮废料，对导向部件加润滑油，保持整洁、无油污、无生锈。

### 5.3 连续模类专项保养

适用触发阈值：**400000模次**。

1. 检查导套、导柱、钢珠衬套的磨损、变形、松动和丢失情况；更换或补齐。
2. 检查上下模压料板、成形顶料板是否开裂崩缺；按情况进行镶拼处理，开裂严重时更换。
3. 检查卸料板螺钉是否断裂、弯曲；断螺钉需钻通并重新攻丝；断裂三个或以上时更换全部卸料螺钉。
4. 检查上模压料板与夹板固定螺钉是否断裂、松动或缺少；断裂三个或以上时更换全部螺钉，缺少时补齐。
5. 检查固定导正销、导向块是否可靠、无松动，是否磨损或缺少；检查浮动导正销、浮料块、顶料销顶出是否顺畅；加固、更换、补齐或调整修配。
6. 检查上下模弹簧是否断裂、变形、压缩量失效，氮气弹簧是否漏气失效；更换异常件；断裂弹簧三个或以上时更换全部弹簧。
7. 检查成型凸模、成型凹模是否损坏或有裂纹，成形表面是否磨损、表面光洁度是否达标；镶补、更换或抛光。
8. 检查冲切凸模、冲切凹模是否损坏或有裂纹，冲切刃口是否磨损钝化；镶补或更换；刃口钝化时更换冲头镶件和凹模镶件。
9. 检查圆冲头、异型小冲头是否弯曲、磨损、钝化或破损；异常三个或以上时更换全部相应冲头。
10. 检查成型滑块、滑槽是否磨损破裂，滑动是否卡死或不顺畅；更换或修配，保证上下往复活动顺畅。
11. 完成后固定所有螺钉，拧紧快换顶丝（必须双顶丝互锁），清理凸凹模和模板锌皮废料，对导向部件加润滑油，保持整洁、无油污、无生锈。

### 5.4 边板类专项保养

适用触发阈值：**400000模次**。

1. 检查导套是否磨损，导柱是否松动、弯曲、变形，钢珠衬套是否磨损、变形或丢失；更换或补齐。
2. 检查上下模压料板是否弯曲、变形或有凹坑；按情况磨平、镶拼或更换。
3. 检查卸料板螺钉是否断裂、弯曲；断螺钉需钻通并重新攻丝；断裂三个或以上时更换全部卸料螺钉。
4. 检查定位销、定位块是否可靠、无松动，是否磨损或缺少；加固、更换或补齐。
5. 检查上下模弹簧是否断裂、变形、压缩量失效，橡皮是否开裂损坏、压缩量失效；同类损坏三个或以上时更换全部相应件。
6. 检查冲切凸模、冲切凹模和拼块是否走位、松动；更换全部销钉并重新装配、校正间隙。
7. 检查冲切凸模、冲切凹模是否损坏或有裂纹，冲切刃口是否磨损钝化；镶补、更换或用磨床磨至锋利，并重新配间隙。
8. 检查圆冲头、异型小冲头是否弯曲、磨损、不锋利，翻边冲头、顶破冲头是否弯曲或破损；异常三个或以上时更换全部相应冲头并重新配间隙。
9. 检查凹模漏料孔、翻边孔顶芯漏料是否顺畅无堵塞，顶芯顶力是否合适，退料切刀是否锋利无缺；堵塞时加大漏料孔并相应减少刃口高度（孔直径1.2至4，刃口高度2.5—5mm）；更换堵塞顶芯、调整顶料力、更换或补齐切刀。
10. 检查侧冲孔滑块、滑槽是否磨损破裂，滑动是否卡死或不顺畅；更换或修配。
11. 完成后固定所有螺钉，拧紧快换顶丝（必须双顶丝互锁），清理凸凹模和模板锌皮废料，对导向部件加润滑油，保持整洁、无油污、无生锈。

## 7. 储放与安全规范

### 7.1 注塑模具储放

1. 入库前型腔面喷防锈油。
2. 非生产状态清除冷却水道残留水；打包前用压缩空气按组吹干。
3. 按留样件确认不良点并采取相应保养措施。
4. 清洁油污、灰尘和浇口套残料；检查行程开关、防尘板、水管、气管、气阀、铭牌等配件完整。
5. 存放在干燥、通风处，严禁室外淋雨或暴晒。
6. 雨季：一季度不生产的模具打开检查防锈；停产期每两季度检查并补喷防锈剂。
7. 不常用模具每月清扫表面灰尘；油漆脱落按公司要求补漆。
8. 定点放置并用平面图标示位置，做到对号入座。
9. 热流道模具保护加热和控制导线，避免挤压。
10. 模具库内保持干净整齐，不得在模具上放杂物、重物，严禁重叠。
11. 无模脚模具底部垫木板或软质水平基座，不得倒放。
12. 无生产计划的在库模具罩外罩，防尘、防锈。
13. 生产完成且不再生产时，允许平放铁插板，便于叉车运输库存。
14. 单边模具不得放在斜坡；长厚比超过3时，前后设置超过一半高度的整套模具防护。

### 7.2 钣金模具储放

1. 存放处地面干净、清洁、干燥。
2. 模具放在干燥、通风处，严禁室外淋雨或暴晒。
3. 雨季按周期检查防锈并补喷防锈剂；不得裸露在模具架外受风吹雨淋。
4. 不常用模具每月清扫表面灰尘，油漆脱落时按规定补漆。
5. 入库前清洁油污、灰尘并用气枪吹净；检查导柱导套、紧固螺栓、气管、运输块、铭牌等配件。
6. 定点放置并用平面图标示位置。
7. 模具上架并分区管理；未上架时放在约300mm高的胶皮或垫板上，防潮防湿。
8. 模具库内保持干净、整齐，不得放置其他杂物、重物。
9. 底部垫木板或软质水平基座，不得倒放。
10. 无生产计划的在库模具罩帆布，防尘、防锈。
11. 简易棚四周使用严密防雨布，确保无间隙；模具架最底层高出地面300mm。
12. 入库前按留样件确认不良点并采取保养措施。
13. 入库前清除模腔并用压缩空气吹净碎屑。
14. 入库前型腔面喷防锈油。

### 7.3 调拨、闲置恢复与记录

- 调往其他基地前：完成下机拆模保养并检查模具完整性；
- 闲置模具恢复生产前：调回使用单位进行拆模保养，提交有效记录后恢复可生产状态；
- 修模、改模或更换备件：同步执行适用保养和点检；只有按 `REPAIR_SYNC_MAINTENANCE` 正常报工时才同时复位产量与时间周期；
- 注塑每日保养、钣金生产前后基础保养、12/24/48小时固定作业及储放检查：只形成轻量记录，不复位任何周期；
- 产量阈值保养、2个月时间保养和修模换件同步保养正常完成：按报工时有效模次和完成时间同时更新周期基准；
- 异常报工、必检项不完整或仍存在未处理异常：不复位任何周期。

### 8.7 故障工时使用规则

1. 匹配时必须同时考虑模具类型、故障类型和故障描述；
2. 每条结果必须返回源表ID，后续报工保存 `source_fault_id`；
3. 相近词不能直接合并，例如“毛刺”“毛剌”“零件毛刺大”是源表中的不同条目；
4. 同一现象可能分别属于“模具异常”和“产品异常”，工时不可跨类别套用；
5. 精确匹配到唯一条目时可以带出标准维修工时；
6. 未精确匹配或出现近似重复时，返回候选条目的源表ID、原始描述和标准工时，由被派工人员选择；
7. 不得自动取最大值、最小值、平均值，也不得默认使用5小时；
8. 标准维修工时用于计划和分析，实际完工必须记录实际工时；
9. 源资料没有根因、正式维修步骤、备件或安全要求，智能体不得据此编造维修方案；
10. 故障工时不参与保养触发或周期复位计算。

## 9. 被派工人员邮件链接报工与异常闭环

### 9.0 邮件报工链接方案

工单完成派工后，Django在派工响应或工单详情中返回：

```text
work_order_id
assignee_id
assignee_name
assignee_email
report_method=WEB_FORM
report_url
report_button_text=提交报工情况
report_form_schema_version=REPORT-FORM-1.0
```

标准报工链接：

```text
GET /report/{work_order_id}
```

报工页面由Django模板提供，不要求人员登录。页面必须展示：

```text
工单编号、模具信息、工单类型、被派工人员、要求完成时间
触发依据、周期处理方式、知识快照版本
本次适用的一份点检知识包及逐项点检清单
```

被派工人员填写：

```text
report_type                 # NORMAL / ABNORMAL
report_summary              # 完成情况或处理说明
inspection_results          # 每项PASS / FAIL / NOT_APPLICABLE
abnormal_items              # 异常报工时必填
photos                      # 按任务或异常要求选填
parts_replaced              # 有更换件时填写
source_fault_id             # 命中故障工时候选时选填
actual_work_hours           # 实际作业工时
abnormal_next_action        # CONTINUE_PROCESSING / CREATE_REPAIR_TASK，异常时可选
```

Django自动记录：

```text
reported_at
effective_mold_cycles_snapshot
report_url
knowledge_snapshot_version
```

提交接口：

```text
POST /report/{work_order_id}                         # HTML表单
POST /api/v1/work-orders/{work_order_id}/report     # JSON接口
```

约束：

1. `report_url` 必须来自Django响应，智能体平台不得自行拼接；
2. 邮件中的点检知识、报工页面展示知识和服务器保存知识快照必须是同一版本；
3. 同一工单重复提交正常报工时返回原结果，不重复结单或复位；
4. 已完成工单再次打开链接时只显示已提交结果；
5. 正常报工校验通过后直接 `COMPLETED`；异常报工进入 `ABNORMAL_REPORTED`；
6. 报工链接只用于比赛测试服务器，不作为正式身份认证机制。

### 9.1 正常报工条件

同时满足以下条件时，可提交正常报工：

1. 所有必检项均已填写；
2. 所有适用项均为合格；
3. 所有不适用项均由被派工人员选择并填写原因；
4. 不存在未处理异常；
5. 必填的处理说明、照片、更换件和实际工时记录已提交；
6. `CHK-STAMP-009` 如适用，已由被派工人员人工选择结果并填写必要说明。

服务器校验通过后：

- 工单状态置为 `COMPLETED` 并自动结单；
- `CYCLE_COUNT_MAINTENANCE`、`CYCLE_TIME_MAINTENANCE`、`REPAIR_SYNC_MAINTENANCE`：同时更新产量基准和时间基准；
- 其他轻量记录和储放检查：保存记录但不更新周期基准；
- 保存本次知识快照版本和实际报工数据。

### 9.2 异常报工条件

出现任一不合格项、部件动作异常、无法现场处置的问题或关键字段缺失时：

- 保存异常项目、异常说明、处理情况、照片、已更换零件和可选故障候选；
- 工单进入 `ABNORMAL_REPORTED`；
- 不自动结单；
- 不复位产量或时间周期；
- 可使用第8节故障表查询候选条目，由被派工人员选择 `source_fault_id`。

### 9.3 异常后的继续处理

#### 可以由原被派工人员继续处理

```text
ABNORMAL_REPORTED
→ 被派工人员选择“继续处理”
→ IN_PROGRESS
→ 完成处理并重新点检
→ 重新提交正常报工或异常报工
```

#### 需要单独修模

```text
ABNORMAL_REPORTED
→ 创建关联修模任务
→ 原保养工单进入 REPAIR_LINKED
→ 修模任务完成
→ 原保养工单恢复 IN_PROGRESS
→ 被派工人员重新点检
→ 正常报工后 COMPLETED
```

原保养工单只有最终正常报工后才结单并按工单类型处理周期复位。整个流程不增加主管审批节点。

### 9.4 工单状态

```text
PENDING_ASSIGNMENT
→ ASSIGNED
→ IN_PROGRESS
→ COMPLETED
```

异常分支：

```text
IN_PROGRESS → ABNORMAL_REPORTED
ABNORMAL_REPORTED → IN_PROGRESS
ABNORMAL_REPORTED → REPAIR_LINKED
REPAIR_LINKED → IN_PROGRESS
```

附加状态：

- `PAUSED`：被派工人员暂停任务并填写原因；
- `ABNORMAL_REPORTED`：已提交异常报工，等待继续处理或建立关联修模任务；
- `REPAIR_LINKED`：已创建关联修模任务，等待修模完成后恢复原工单。

## 10. 派工知识包

派工邮件或任务详情至少包含：

```text
【模具信息】
模具编号、名称、类型、位置、开发吨位或LC分类、明确的mold_category

【工单信息】
工单编号、工单类型、当前状态、被派工人员、要求完成时间

【触发依据】
规则ID、当前有效模次、周期基准模次、差值、阈值、时间基准、触发原因

【周期处理】
本工单是否复位产量周期、是否复位时间周期

【本次作业范围】
匹配本知识库中的每日保养、生产前后基础保养、周期专项保养、下机拆模保养、同步保养或入库处理

【操作步骤】
逐项显示对应保养内容

【点检清单】
点检对象、判定标准、方法、结果、不适用原因、异常说明

【故障候选】
源表ID、故障类型、原始描述、标准维修工时；近似条目由被派工人员选择

【报工入口】
`report_method=WEB_FORM`、Django返回的 `report_url`、按钮文字“提交报工情况”、报工表单版本

【报工要求】
被派工人员点击邮件中的报工链接，查看同一知识快照并填写完成情况、点检结果和实际工时；正式周期保养正常报工后同时复位产量和时间周期；轻量记录不复位；异常报工不结单、不复位，并进入继续处理或关联修模流程
```

## 11. 智能体检索与回答限制

- 触发判断只使用第一部分；
- 不引用模具寿命分级、历史一保/二保/三保周期或外部A级/B级/C级分类；
- 不生成主管、管理员审批、审核或验收环节；
- 达到触发条件时按规则自动建立 `PENDING_ASSIGNMENT` 工单，不只返回提示文本；
- 派工后必须使用Django返回的 `report_url` 生成邮件报工按钮；LLM不得自行编造或改写报工链接；
- 比赛服务器使用调用方提供的 `effective_mold_cycles`，不得擅自根据产品件数或型腔数换算；
- 不根据模具名称、一级位置或二级位置猜测 `LC109` 属于连续模类还是边板类，必须读取明确的 `mold_category`；
- 日常、生产前后、固定频次和储放记录不得复位周期；
- 正式周期保养正常报工后同时复位产量和时间周期；
- 点检标准按源表原文返回，不擅自修改比较符号或判定条件；
- `CHK-STAMP-009` 必须由被派工人员人工判定，智能体不得自动比较；
- 故障工时必须按“模具类型＋故障类型＋故障描述＋源表ID”追溯；近似结果只返回候选；
- 源资料未提供维修根因和正式维修步骤时，应明确说明资料不足，不得编造；
- 所有回答应携带规则ID、知识ID或故障源表ID，便于追溯。
